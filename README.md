# Geometrizando React

> Aplicacao React do projeto Geometrizando, com visualizacao e calculo de formas geometricas, desenvolvida com Create React App.

## Stack

- React

## Prerequisitos

- Node.js v14+

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/geometrizando-react.git
cd geometrizando-react

# Instale as dependencias
yarn install

# Inicie a aplicacao
npm start
```
